什么是 STORYFORGE？

StoryForge 是一个 AI 长篇多 POV 小说创作 IDE。
它不是又一个聊天界面 —— 而是为"花园派"（discovery writing，马丁式探索写作）量身打造的导演式创作工具。

// 花园派创作哲学

设定好世界与人物，让角色顺性格自由生长。
AI 码字 ~80%，作者是导演 —— 只在宏观分支节点决策 + 局部微调。
记住大方向与目的地，防烂尾，拥抱涌现。

核心模型：POV 探照灯 · 时空河流 —— 故事时空是一条奔流的河，所有支线在同一时间轴并进； 作者把 POV（视点人物）探照灯打在最具冲击力的角落。一章 = 一个 POV，马丁式多 POV 轮流叙事。

核心功能

从宏观支线规划到微观场景打磨，一站式创作体验。

▲ 功能全景：写作台各模块标注

🗺️

时空工作台

泳道时间轴 + 节点星图，多支线并进可视化。每章一张框架卡（时间/地点/人物/事件），可手填或一键从正文提取。AI 推荐最佳 POV 视点。

✍️

IDE 写作台

9 面板可停靠布局。章节、设定、人物、心法、AI 生成、设定沉淀……所有面板可自由拖拽排列，打造你的专属工作区。

🤖

AI 情节生成

渐进式建议：先给 1 个 → 换一个 / 多个 / 反馈重写。一次生成 500~3000 字完整场景。候选自动快照模型、采样参数，横向对比优化提示词。

📐

四层约束引擎

时代背景（全局）+ 在场人物 + 创作心法 + 支线大方向 → 自动拼装为结构化 prompt。全部肯定式诱导，禁止否定式约束。

📚

世界书选择性注入

常驻条目恒注入，关键词条目仅在上下文命中时激活。分层挂载（通用宇宙 / 当前副本 / 主角团），多书复用。

⚗️

设定沉淀

章末一键 AI 提取设定 → 人工审阅 → 入库世界书。独立出口不污染写作候选流。可编辑提取提示词，选目标世界书，一次设定多书复用。

🔀

场景多版本

同一处正文的多个写法，左右切换对比。可归并相邻段落为一个多版本节点。落稿只取采用版本，其余保留备选。

🔗

Session 连续流

连续对话流跨章运行，写到上下文上限 → AI 总结 → 开新 session。摘要写入世界书条目，长篇一致性不丢失。

💾

一书一卡 · 双源保真

每本小说 = 独立载体卡。Session 文件为权威正文，每次保存自动备份，误操作可恢复。

高自由度布局

每个模块都可以自由拖拽、停靠、调整大小，按你的创作习惯定制工作区。

▲ 所有面板可自由拖拽排列

开发历程

从需求调研到功能落地，7 个 Step 迭代。

STEP 1
需求与调研 — 花园派创作流分析、业界对标（Sudowrite / NovelCrafter）
STEP 2
原型设计 — 4 轮 HTML demo 迭代（泳道 → 星图 → 整合 → IDE 写作台）
STEP 3
前端骨架 — Vite + React + dockview 可停靠 IDE 布局 + 主题系统
STEP 4
最小真链路 — 编辑器 → 后端 → OpenRouter 流式 → 千字续写
STEP 5
持久化 — 小说 ↔ chat 双向映射，旧 UI 可加载一问一答
STEP 6
多本小说 — 书库索引 + 一书一卡迁移 + 世界书绑定
STEP 7
阶段二 — Session 连续流 / 场景多版本 / 世界书选择性注入 / 候选元数据 / 设定沉淀
